# Frontend Portfolio

Portfolio personnel - React + Vite + Tailwind CSS.

## Stack
- React 18 + Vite
- Tailwind CSS
- Framer Motion
- React Router DOM v6

## Installation

```bash
npm install
npm run dev
```

## Pages
- Home, About, Projects
- Skills (avec radar chart)
- Experience, Certifications
- Contact

## Scripts

```bash
npm run dev     # Développement
npm run build   # Production
npm run preview # Preview build
```

Port: `3001` | Thème: Cyan/Blue
